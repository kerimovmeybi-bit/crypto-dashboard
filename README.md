# 🚀 Crypto Dashboard (Трекер криптовалют)

Современное веб-приложение для отслеживания актуальных курсов криптовалют в реальном времени, разработанное на **React** и **TypeScript**. Проект включает в себя аналитику цен, интерактивные графики, конвертер валют, систему избранного и сравнение котировок на различных биржах.

---

## 🛠 Стек технологий

* **Frontend:** React, TypeScript, Vite
* **Стилизация:** CSS Modules / CSS Variables (с поддержкой тем)
* **Анимации:** Framer Motion
* **Иконки:** Lucide React
* **API:** CoinGecko Public API
* **Деплой:** Vercel

---

## ✨ Основные функциональные возможности

1. **📊 Живой список криптовалют:** Загрузка топ-20 монет с актуальными ценами и суточным изменением стоимости.
2. **📈 Мини-графики (Sparklines):** Векторные SVG-графики тренда цены за последние 7 дней прямо на карточках монет.
3. **🔍 Умный поиск:** Мгновенная фильтрация монет по названию или тикеру.
4. **⭐ Избранное (Watchlist):** Возможность добавлять монеты в избранное с сохранением данных в `localStorage`.
5. **🧮 Конвертер валют:** Интерактивный калькулятор для быстрого пересчета любой криптовалюты в доллары USD.
6. **🏢 Сравнение цен на биржах:** Детальная модальная карточка монеты с актуальными котировками на различных биржах (Binance, Kraken и др.) и ссылками на торговлю.
7. **🌓 Переключатель тем:** Плавное переключение между темной (Dark) и светлой (Light) темами с сохранением выбора пользователя.
8. **📱 Адаптивный дизайн:** Интерфейс оптимизирован под любые устройства (ПК, планшеты, смартфоны).
